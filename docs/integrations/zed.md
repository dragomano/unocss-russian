# Расширение для Zed

Расширение от сообщества, которое добавляет поддержку [UnoCSS](https://github.com/bajrangCoder/zed-unocss) в редактор Zed.

:::info
Важно: Это **расширение, поддерживаемое сообществом, а не командой UnoCSS**. Оно не проходит проверку и не поддерживается официально разработчиками UnoCSS. Пожалуйста, проводите собственную проверку перед использованием. Если у вас возникнут проблемы с этим расширением, сообщайте о них в репозиторий [bajrangCoder/zed-unocss](https://github.com/bajrangCoder/zed-unocss).
:::

## Установка

Через менеджер расширений Zed установите [расширение unocss](https://zed.dev/extensions/unocss)
